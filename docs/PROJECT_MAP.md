# Project map: session journal

## Application

| File | Responsibility |
| --- | --- |
| [pubspec.yaml](../pubspec.yaml) | Package identity, SDK constraint, dependencies, and Flutter asset configuration. |
| [pubspec.lock](../pubspec.lock) | Exact dependency resolutions for reproducible application builds. Generated by Pub. |
| [analysis_options.yaml](../analysis_options.yaml) | Enables the Flutter lint rules used by analysis. |
| [lib/main.dart](../lib/main.dart) | Dart entry point; delegates startup to bootstrap. |
| [lib/app/bootstrap.dart](../lib/app/bootstrap.dart) | Mounts the application. Future resource initialization and injection belong at this boundary. |
| [lib/app/app.dart](../lib/app/app.dart) | Root widget configuring MaterialApp, theme, title, and initial page. |
| [lib/app/app_router.dart](../lib/app/app_router.dart) | Centralized journal, editor, and about routes. |
| [lib/features/journal/models/journal_entry.dart](../lib/features/journal/models/journal_entry.dart) | Immutable entry content and timestamps. |
| [lib/features/journal/data/journal_repository.dart](../lib/features/journal/data/journal_repository.dart) | Storage contract and session-only implementation. |
| [lib/features/journal/bloc/journal_bloc.dart](../lib/features/journal/bloc/journal_bloc.dart) | Explicit events, immutable state, validation, and sequential repository operations. |
| [lib/features/journal/views/journal_page.dart](../lib/features/journal/views/journal_page.dart) | Journal list, empty/loading/error states, and preview warning. |
| [lib/features/journal/views/journal_editor_page.dart](../lib/features/journal/views/journal_editor_page.dart) | Draft editing, save/delete actions, and unsaved-change protection. |
| [test/journal_bloc_test.dart](../test/journal_bloc_test.dart) | Repository CRUD, validation, failure/retry, and queued saves. |
| [lib/app/app_identity.dart](../lib/app/app_identity.dart) | Shared user-facing name and tagline, independent of the package identifier. |
| [lib/core/theme/app_tokens.dart](../lib/core/theme/app_tokens.dart) | Central definitions for colors, typography, spacing, radii, and duration. |
| [lib/core/theme/app_theme.dart](../lib/core/theme/app_theme.dart) | Converts design tokens into Flutter's ThemeData and component themes. |
| [lib/features/onboarding/views/welcome_page.dart](../lib/features/onboarding/views/welcome_page.dart) | Scrollable welcome layout with design principles and an explicit preview warning. |
| [lib/features/onboarding/widgets/privacy_principle_card.dart](../lib/features/onboarding/widgets/privacy_principle_card.dart) | Reusable presentation of a principle using an icon, title, and description. |
| [lib/features/onboarding/widgets/build_info_dialog.dart](../lib/features/onboarding/widgets/build_info_dialog.dart) | Opens and renders the dismissible information dialog; respects reduced animation settings. |
| [test/widget_test.dart](../test/widget_test.dart) | Journal CRUD, discard/delete confirmations, about dialog, and small-screen/large-text/keyboard layout. |

## Native integration

| File | Responsibility |
| --- | --- |
| [android/app/src/main/AndroidManifest.xml](../android/app/src/main/AndroidManifest.xml) | Android application/activity declarations and launcher display name. |
| [ios/Runner/Info.plist](../ios/Runner/Info.plist) | iOS application metadata, launcher display name, and supported orientations. |
| [.gitignore](../.gitignore) | Starter ignore rules for generated outputs and local tooling files. No Git repository was present at the foundation checkpoint. |

The remaining platform files are Flutter-generated starter infrastructure and
have not been turned into privacy/security implementations.
